# X-Ray Analysis

**Window:** `?modal=xray` — Screenplay analysis dashboard (transparent TitleBar with `28px` rounded window controls, no header icon badge)

The X-Ray window is a comprehensive screenplay analysis dashboard with pill-tab modes (Statistics / Timing / Characters / Connections / Pacing).

## Features

### Scene Analysis
- Scene-by-scene breakdown with statistics
- Character appearance tracking
- Location density analysis
- Scene length distribution

### Dialogue Analysis
- Character speaking time distribution
- Dialogue vs action ratio
- Character interaction matrix
- Most/least talkative characters

### Structure Analysis
- Act structure visualization
- Pacing chart (scene length over time)
- Page count projection
- Story structure template comparison

### Production Reports
- Character breakdown (by gender, by scene count)
- Location list
- Prop and costume counts (tag-based)
- Scene count by day/night, interior/exterior

### Export
All analysis data can be exported as CSV for external processing.
