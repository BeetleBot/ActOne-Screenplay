# Sprint Tracking

The sprint tracker is a timed writing session tool for productivity.

## Starting a Sprint

1. Set a word count goal in the Sprint sidebar tab (Tab 7 — Sprint)
2. Click **Start Sprint**
3. A timer begins counting up
4. Words typed during the sprint are counted in real-time

## During a Sprint

The status bar displays:
- Sprint timer (MM:SS / total minutes)
- Word count achieved
- Words per minute (WPM)
- A pulsing dot indicator

The Sprint sidebar shows more detail:
- Elapsed time
- Current word count
- Words per minute
- Goal progress bar
- Pause/Resume/Stop controls

## History

Completed sprints are saved to `sprint_data.json` in the `.actone` bundle:
- Date and time
- Goal
- Words written (words typed *during* the sprint, not the file total)
- Duration

## Use Cases

- NaNoWriMo-style writing challenges
- Daily word count targets
- Focused writing sessions with time pressure
- Tracking writing productivity over time
