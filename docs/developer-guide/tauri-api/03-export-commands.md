# Export Commands

## `export_pdf`

Full PDF export pipeline with native save dialog. Parses Fountain text, renders pages via krilla, and saves.

```typescript
invoke<string | null>("export_pdf", {
    fountainText: string,
    paperSize: "Letter" | "A4",
    fontFamily: string,
    elementFormats: ElementFormats,
    mirrorSceneNumbers: "Off" | "LeftSide" | "Mirror",
    exportSections: boolean,
    exportSynopses: boolean,
    exportTitlePage: boolean,
    exportSceneColors: boolean,
    revisedLines: number[],
    watermarkHeader: string,
    watermarkFooter: string,
    watermarkCenter: string,
    watermarkCenterImage: string | null,
    watermarkOpacity: number,
    watermarkHeaderOpacity: number,
    watermarkFooterOpacity: number,
    watermarkCenterOpacity: number,
    watermarkFontSize: number,
    watermarkColor: string,
    scriptFonts: Record<string, string>,
});
```

**Returns:** Saved file path or `null` if cancelled.

**Parameters (18 total):**

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `fountainText` | `string` | — | Raw Fountain screenplay text |
| `paperSize` | `"Letter" \| "A4"` | `"Letter"` | Page size |
| `fontFamily` | `string` | `"courier-prime"` | Base font family |
| `elementFormats` | `ElementFormats` | See below | Per-element bold/italic/underline |
| `mirrorSceneNumbers` | `"Off" \| "LeftSide" \| "Mirror"` | `"Off"` | Scene number positioning |
| `exportSections` | `boolean` | `true` | Include section headers |
| `exportSynopses` | `boolean` | `true` | Include synopsis lines |
| `exportTitlePage` | `boolean` | `true` | Include title page |
| `exportSceneColors` | `boolean` | `true` | Include scene colors |
| `revisedLines` | `number[]` | `[]` | Line numbers to mark as revised |
| `watermarkHeader` | `string` | `""` | Header watermark text |
| `watermarkFooter` | `string` | `""` | Footer watermark text |
| `watermarkCenter` | `string` | `""` | Center watermark text |
| `watermarkCenterImage` | `string \| null` | `null` | Center watermark image path |
| `watermarkOpacity` | `number` | `0.08` | Center watermark opacity (0-1) |
| `watermarkHeaderOpacity` | `number` | `0.08` | Header opacity |
| `watermarkFooterOpacity` | `number` | `0.08` | Footer opacity |
| `watermarkCenterOpacity` | `number` | `0.08` | Center image opacity |
| `watermarkFontSize` | `number` | `48` | Watermark font size (pt) |
| `watermarkColor` | `string` | `"#000000"` | Watermark color |
| `scriptFonts` | `Record<string, string>` | `{}` | Per-script font overrides |

**ElementFormats structure (snake_case keys):**
```typescript
interface ElementFormats {
    scene_heading: ElementFormat;
    action: ElementFormat;
    character: ElementFormat;
    parenthetical: ElementFormat;
    dialogue: ElementFormat;
    lyrics: ElementFormat;
    transition: ElementFormat;
    shot: ElementFormat;
    centered_text: ElementFormat;
}
interface ElementFormat { bold: boolean; italic: boolean; underline: boolean; }
```

**Default formats:** Scene headings and shots are bold by default; all others plain.

## `generate_pdf_bytes`

Generates PDF bytes in memory without a save dialog. Used by ExportModal for PDF preview and programmatic export.

```typescript
invoke<number[] | null>("generate_pdf_bytes", {
    fountainText: string,
    paperSize: "Letter" | "A4",
    fontFamily: string,
    elementFormats: ElementFormats,
    mirrorSceneNumbers: "Off" | "LeftSide" | "Mirror",
    exportSections: boolean,
    exportSynopses: boolean,
    exportTitlePage: boolean,
    exportSceneColors: boolean,
    revisedLines: number[],
    watermarkHeader: string,
    watermarkFooter: string,
    watermarkCenter: string,
    watermarkCenterImage: string | null,
    watermarkOpacity: number,
    watermarkHeaderOpacity: number,
    watermarkFooterOpacity: number,
    watermarkCenterOpacity: number,
    watermarkFontSize: number,
    watermarkColor: string,
    scriptFonts: Record<string, string>,
});
```

**Returns:** PDF bytes as `number[]`, or `null` on failure.

## `get_page_breaks`

Dry-run page break calculation — renders the PDF mentally and returns line numbers where page breaks occur.

```typescript
invoke<number[] | null>("get_page_breaks", {
    // Same 18 parameters as export_pdf
});
```

**Returns:** Array of 0-indexed line numbers where page breaks fall, or `null` on failure.

---

## `save_pdf_dialog`

Opens a native save dialog for PDF and writes pre-generated bytes.

```typescript
invoke<string | null>("save_pdf_dialog", { bytes: number[] });
```

**Parameters:**
- `bytes: number[]` — PDF bytes to write

**Returns:** Saved file path or `null` if cancelled.

## `select_watermark_image`

File picker for watermark images.

```typescript
invoke<string | null>("select_watermark_image");
```

**Filters:** PNG, JPG, JPEG, BMP images.

**Returns:** Selected image path or `null`.
